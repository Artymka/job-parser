- добавить проверку нескольких proxy
- добавить retry middleware

Получение сообщений из каналов:
1. Перебираем все диалоги (пагинация не понадобится почти наверняка)
2. Для каждого диалга проверяем, является ли он каналом
3. Если это канал, читаем историю сообщений

Структура:
Есть тикер, который каждые 12 часов запускает функцию, которая возвращает последние сообщения из всех каналов (в виде массива сторк).
Эта функция по-новой устанавливает соединение с telegram user api, авторизуется, собирает список чатов, а только после собирает последние сообщения.
Продюсер закидывает полученные сообщения в kafka.

Также в качестве второй программы (процесса) крутится консьюмер, который каждые ~12 часов читает сообщения из kafka и просто выводит их в консоль.
